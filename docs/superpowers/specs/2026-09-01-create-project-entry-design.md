# 새 프로젝트 생성 진입점 Design

작성일 2026-09-01 · 브랜치 `main`

## 배경

관리자 UI는 프로젝트가 하나도 없을 때만 `CreateProjectPage`를 보여준다. 데모 프로젝트를 만든 뒤 다른 로컬 앱을 붙이려면 새 프로젝트를 추가할 화면 진입점이 없다.

## 목적

이미 프로젝트가 있는 사용자도 대시보드에서 새 프로젝트 생성 화면으로 들어가 다른 앱용 프로젝트를 만들 수 있게 한다.

## 범위

**한다**

- 대시보드 헤더에 `새 프로젝트` 버튼을 추가한다.
- 기존 `CreateProjectPage`를 재사용한다.
- 생성 성공 시 새 `projectId`를 선택 프로젝트로 저장하고 설치 안내 화면으로 보낸다.

**하지 않는다**

- 생성 취소/뒤로가기 버튼은 만들지 않는다.
- 프로젝트 삭제나 복제는 만들지 않는다.
- 프로젝트 생성 API 계약은 바꾸지 않는다.

## 동작

대시보드에서 `새 프로젝트`를 누르면 프로젝트 생성 폼이 열린다. 사용자가 이름과 허용 도메인을 입력해 생성하면 기존 온보딩과 동일하게 설치 스니펫 화면으로 이동한다. `trace.selectedProjectId`에는 새 프로젝트 ID가 저장된다.
