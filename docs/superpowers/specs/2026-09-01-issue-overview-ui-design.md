# 문제 한눈에 보기 UI 설계

## 목표

관리자 대시보드의 문제 목록을 테이블 중심 화면에서 우선순위가 바로 보이는 인박스형 목록으로 개선한다.

## 범위

- 대상 화면은 관리자 대시보드의 `문제 목록` 영역이다.
- API, DB, SDK 이벤트 수집 로직은 변경하지 않는다.
- 기존 `Issue` 응답 필드만 사용한다.
- 상세 드로어 진입은 유지하고, 행 전체 클릭과 보기 버튼 모두 같은 상세 열기 동작을 수행한다.

## UX

- 목록 상단에 `긴급`, `주의`, `낮음` 건수를 요약해 전체 상태를 먼저 보여준다.
- 각 문제는 한 행에서 심각도 점수, 상태, 추세, 영향 세션/사용자 수, 화면 경로, 마지막 발견 시각을 함께 보여준다.
- 기본 정렬은 `severityScore` 높은 순, 같은 점수에서는 `lastSeenAt` 최신 순이다.
- 빈 상태 문구는 기존과 동일하게 유지한다.

## 표시 규칙

- `severityScore >= 80`: 긴급
- `severityScore >= 50 && severityScore < 80`: 주의
- `severityScore < 50`: 낮음
- `trend`는 `up`, `flat`, `down`을 각각 `증가`, `유지`, `감소`로 표시한다.
- 시간은 기존 관리자 UI formatter인 `formatKoreanDateTime`을 사용해 KST로 표시한다.

## 테스트

- `IssueTable` 컴포넌트 테스트를 추가한다.
- 테스트는 정렬, 심각도 요약, 행 전체 클릭, KST 마지막 발견 시각 표시를 검증한다.
